# character-generation-skill · 部件化角色生成与导出

一套「**一个 HTML + 每角色一个 .js**」的角色资产生产线。角色 128px 高、纯 SVG 矢量、
无骨骼无动画，部件可单独导出，同 Style 部件尺寸差异强制 ≤20%（换装 / 换皮不穿帮）。

- **存档即文件**：每个角色一个自包含 `.js`，双击 `app/Editor.html` 即可预览导出（file:// 直开，免服务器）
- **基础部件三组单选**（页面卡片点选）：
  - **头部**（headsets）：头型+发型整头替换；
  - **表情**（faces）：单选一个，画在头上层（没有 noBaseFace 机制，基础表情就是一个普通选项）；
  - **身体**（bodies）：一套 = `legL/legR/torso/armL/armR` 5 件，**整体替换**（换装=换整套）
- **挂件机制**：预定义挂点（head / body / back / hand_l / hand_r / foot_l / foot_r）+ 偏移，
  带 `cat` 分类——**跨分类复选、分类内单选（可再点取消）**，数量不限，可跨同风格角色复用
- **一致性护栏（设计规则，不进 UI）**：同 Style 角色的基础件（head + body 五件）bbox 宽高差异须 ≤20%，
  写角色时自查；页面上**不**展示数据表，只保留贴边 / 越界部件警告
- **预览拖动定位**：舞台上按住任意部件（头/表情/身体件/挂件，z 序顶层优先命中）拖动即微调位置；
  位移存 `item.__pos`，渲染/贴边警告/导出全部即时生效；拖回原位（<0.5px）自动还原。
  **拖出预览框（bbox 出界一丁点）→ 本次拖动作废、部件弹回拖动前位置**；
  启动/重载时已越界的存档位移自动重置到预览框中心（`sanitizePos`，每角色一次性）。
  已授权文件夹时松手即静默写盘（位移以 translate 包裹层并入 registerEdits 补丁，
  重载时归一化还原为运行期位移）；未授权则暂存内存，下次任意保存时一并写盘
- **来源路径显示**：预览框下方显示当前角色文件来源（分页跟随）——FSA 授权 = 授权文件夹/子目录/文件名，
  http = 相对路径，手选文件 = 仅文件名（浏览器安全限制拿不到绝对路径）；
  行首「**选择路径**」按钮随时重选角色文件夹（直接弹目录选择、不走重连；无 FSA 降级手选 .js）
- **导出**：全部资源（每个头部/表情/身体件/挂件）+ 整角色 + **选中部件** × SVG / PNG
  （PNG 尺寸倍率为浮点输入框，1 位小数，区间 (0,10]，非法/越界输入门闩纠正，文件名 @Nx.png 跟随），
  各自可打 ZIP（「选中」= 预览当前装配：单选的头/表情/身体套 + 已点选挂件，无独立勾选框；身体套展开为 5 件）。
  部件导出按几何 bbox + 描边外扩裁切（getBBox 不含描边，pad = 1 + 最大 stroke-width，SVG 与 PNG 画布共用 pngSize，杜绝粗描边被裁）
- **手动编辑器**：每张资源卡 ✎ 进入；Ctrl+Z 撤销 / Ctrl+Y 重做（≤60 步，快照整栈重建、跨形状增删有效）：
  - **形状/锚点/手柄**：path 锚点拖拽（两侧手柄随行）、曲线手柄拖拽、数值输入；＋线/＋环（视图中央新增，
    插在选中形状上层）、－形状；＋锚点（曲线段 De Casteljau 平滑细分，两侧手柄保留、曲线形状不变；直线段插直点）、
    －锚点（相邻段降为直线；删起点则后继成为新起点）；＋/－入柄·出柄（相邻 L 段升 C——手柄沿直线 1/3、2/3 放置；
    C/Q 段降回 L。柄属于段：删入柄会同时去掉前锚点的出柄）
  - **颜色**：填充/描边取色器 + 「无」= none（none 状态色块仍可点击、选色即恢复）；描边宽恒显示，
    无描边时为 0，给宽度 >0 自动恢复上次描边色
  - 锚点/柄覆盖层为半透明圆点（填充 0.45~0.7，描边实线），不挡路径
  - **保存**：「完成并保存」把编辑结果作为 override 写回角色 .js（文件末尾 `/*__CHARFORGE_EDITS__*/registerEdits(...)`
    单行补丁，重复保存自动替换；运行时 override 优先于 draw 输出——**改 palette 不会影响已编辑资源**）

## 30 秒决策

| 你要做什么 | 走哪条路 |
|---|---|
| 新建一个角色 | 读 `references/format-spec.md` → 写 `<角色名>.js` → 写进 `app/chars/`（默认角色文件夹）→ 打开页面验收 |
| 新角色要和现有角色同风格 | **以现有角色文件为锚**：palette 色板、平涂无描边风格（`LINE #4A3B42` 只用于五官/细节线）、比例节奏照抄，只改造型不改尺寸基准 |
| 加挂件（帽子/武器/眼镜…） | 在角色文件 `attachments` 数组加一项，写好 `cat` 分类（同分类自动互斥单选） |
| 加表情 / 换发型 / 换套装 | 分别往 `faces` / `headsets` / `bodies` 数组加一套（每类 ≥2 套时页面出现切换卡片） |
| 手动微调某个资源的形状 | 部件卡右上角 **✎** 打开 SVG 编辑器：锚点/曲线手柄拖拽 + 数值输入，Ctrl+Z/Y 撤销重做，完成自动写回角色 .js |
| 换角色所在文件夹 | 预览下方「选择路径」按钮：弹目录选择即加载（自动下潜 chars/ 子目录），路径行同步刷新 |
| 验收 / 出货 | 打开 `app/Editor.html`：部件卡片无贴边红框 → 导出 ZIP |

## 新建角色的固定流程（AI 执行）

1. **问 Style**（如用户没给）：新风格 → 让用户给参考（图 / 文字 / 已有角色文件）；
   同风格追加 → 读现有角色文件拿 palette + anchors + 比例。
2. **写角色文件**：严格按 `references/format-spec.md`。自包含（绘图原语内联，照抄 `app/chars/girl.js`
   开头那套 helper），文件名 = 角色名。**同风格比例基准别动**（见 format-spec 的纵向节奏表）。
3. **收纳**：写进 `app/chars/`（默认角色文件夹）即完成——HTML 自动发现，**不改 Editor.html**。
   （file:// 下授权任意文件夹都能读：授权文件夹顶层无 .js 时会自动下潜其 chars/ 子目录；
   保存补丁写回角色来源目录，不会落到上层。）
4. **验收**：
   - `node --check app/角色名.js`
   - 打开页面肉眼看：五官居中、部件无错位、挂件挂在挂点上、
     每组套装/挂件切换一次都正常（默认套装是第 1 套）
   - 页面内：部件卡片无红色贴边警告
   - 点一次「全部打包 ZIP」→ 解包验证 PNG 魔数与文件数（文件数 =
     头部套数+表情数+身体套数×5+挂件数，SVG/PNG 各一份）
5. **交付**：`app/` 目录整个给用户（html 与 `chars/` 一起拷走；file:// 下授权任意文件夹也能读）。

**角色加载机制**（Editor.html 自动，勿手挂）：
- http(s) 打开：fetch 本页所在目录索引 → 自动加载其中全部 .js（目录索引需服务开启；json 列表也支持）；
- file:// 双击打开：File System Access 流程——首次点「📂 选择角色文件夹」授权一次（showDirectoryPicker，
  弹的是系统文件夹选择框，无法绕过），句柄存 IndexedDB；之后每次打开**权限仍在就启动静默直读**，
  权限过期则按钮变「一键重连」（只弹「允许」条，不重新选文件夹）；
- 兜底：不支持 FSA 的浏览器点按钮自动落到「加载角色文件」手动多选 .js。
- **编辑器保存**：直接写回原文件，不落下载——①有文件夹句柄 → 直写（权限过期借保存点击续期）；
  ②无句柄 → 现场弹一次文件夹授权（之后永久静默直写，取消则不保存）；③无 FSA 的浏览器才下载替换。

## 规则与红线

- **基础部件三组 + 分类挂件**：`headsets / faces / bodies / attachments(cat)`；
  bodies 套装 5 件 key 固定 `legL/legR/torso/armL/armR`，缺件该件不画。
  除了这四组数组，其余任何部件概念都不存在——「再加一种基础件」先质疑需求。
- **20% 规则**：同 style 的基础件 bbox 宽高差异 ≤20%。设计手段：双臂统一垂放姿态、
  手部挂点坐标两角色保持一致（可直接复用武器挂件）、发型宽度别差太多、
  变体套装尽量复用同一几何只换色/局部。
  注意 `getBBox` **不含描边**，细长线条部件的视觉宽度比 bbox 大。
- **128px 画布只约束两处，部件导出已自适应**：部件导出按部件自身 bbox + 描边外扩
  （pad = 1 + 最大 stroke-width），画到 `0~128` 界外也**完整导出不裁切**；
  受画布限制的只有**预览舞台**（128 viewBox 视觉裁剪，画出边界的部分预览看不见）和
  **整体导出**（full SVG/PNG 按 128 画框，超出部分被切）。
  贴边警告（卡片红框 + 面板汇总）仍会标红：含义是「预览不可见 / 整体图被切 / 偏离规范」，
  建议归位清零，而非硬性报废。
- **角色 id 全局唯一**，重复 id 会在「加载问题」面板报错。
- 同一文件多处修改**串行**做（并行 Edit 会静默丢一处）。

## 已踩过的坑（改代码前先看）

- **挂件 draw 只能用挂点局部坐标，不能写画布绝对坐标**：页面会把挂件整体
  translate 到锚点上——写成绝对坐标（如把头画布上量来的 `M45 22...` 直接搬进
  帽子挂件）= 挂件平移 (anchor) 飞出身体。换算公式：局部 = 绝对 − anchors[slot]。
  表情挂件里复用基础件辅助函数同理：`bigEye(72.8)` 要传 `bigEye(8.8)`。
  验证：舞台截图肉眼看 + innerHTML 应含局部坐标路径串。
- **buildZip 只吃 `Uint8Array`**：塞 `ArrayBuffer`（无 `.length`）或 PNG `Blob` 会得到
  `offset is out of bounds`——文本用 `TextEncoder().encode()` 直出的 `Uint8Array`，
  PNG 先 `blob.arrayBuffer()` 再包 `Uint8Array`。
- **PNG 导出防 NaN**：画布尺寸必须 `isFinite && >0`，画布 0 尺寸时 `toBlob` 返回 null 零报错。
- **换算旧资产坐标**（200 宽 → 128）：逐点套 `x' = 64+(x-100)*0.61` 重算，
  别心算——女孩发盖曾因一组控制点算错整片偏左，渲染出尖刺刘海。
- **角色发现是全自动的**（html 同级及 chars/ 下的 .js，顶层无 .js 自动下潜 chars/），HTML 里没有挂载清单
  ——加角色只需放文件，**不改 Editor.html**。file:// 下 fetch 目录被 CORS 拦是预期，页面走「选择文件夹」授权。
- **`exportZip` 只打包当前页角色**（SVG+PNG 各 = 头部套数+表情数+身体套数×5+挂件数，
  另加整体 2 件），双角色要翻页各导一次。
- **页面渲染函数必须防 `def` 为空**：0 角色时 `renderAll` 也会跑全部 renderXxx——
  每个 render 分支开头 `if (!def) return`（曾因缺防御在空态抛错，炸掉后续面板渲染且只在 console 露出）。
- **页面里没有角色文件的原语**（ell/shape 等）：卡片预览要画脸底之类的内容，
  直接内联 `<ellipse .../>` 字符串，别调角色文件里的 helper（`ell is not defined`）。
- **20% 一致性 vs 还原度的取舍**：发型特征差异大（垂发 vs 短发）时 head bbox 必超 20%
  ——若两角色部件无互换场景（固定 CP），保留标红保还原度，只把 body/legs/arms 收敛进线，
  并向用户说明标红原因；能压的先压（ legs 起点上提、裙摆收窄、脖子下移都是低代价抓手）。
- **VTracer/描摹 SVG 不可路径级拆分**（绝对坐标堆叠 blob 无语义分层）：正确路线 =
  渲染看图 → 统计 fill 取色板 → 按 6 基础件规范重建，别试图直接给路径分组。

## 能力边界

**能做到**：128px chibi（可调比例的其他头身比，需改纵向节奏基准）、同风格批量角色、
挂件无限扩展、跨角色复用挂件、SVG/PNG/ZIP 导出、引擎直用（PNG 按部件 bbox+描边自适应边距，不裁切）。

**做不到**：骨骼动画 / 帧动画（无 pivot 关节，动画请在游戏引擎里另做，别在这加）；
位图 / 厚涂风格；大于 128 的精细立绘（放大会糊，矢量本身无损但细节量按 128 设计）。
