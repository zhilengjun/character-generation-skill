# character-generation-skill 角色存档格式规范（真源）· 套装变体格式 v2

> 每个角色一个自包含 `.js`，调用全局 `registerCharacter(def)` 注册。
> 现成样例：`app/chars/girl.js`（女孩）、`app/chars/boy.js`（男孩）——写新角色先读其中一个再动手。

## 顶层结构

```js
(function (global) {
  'use strict';
  // ── 绘图原语（自包含，从样例文件照抄：stroked/limb/shape/ell/circ/rrect/dot）──
  var LINE = '#4A3B42';   // 五官/细节线色（发缝、眉眼嘴、衣褶），不做轮廓描边
  // 风格 = 平涂无描边：所有填色形状不带 stroke，部件靠色差区分；
  // 相邻同色风险件（袖 vs 衣身、裤 vs 鞋）必须加深/减淡一档错开。

  global.registerCharacter({
    id: 'girl',                    // 全局唯一，= 导出文件名前缀
    name: '女孩',                  // 页面显示名
    style: 'chibi-3head-warmline-128',  // 风格标识：同 style 互做 20% 一致性检查
    canvas: { w: 128, h: 128 },    // 画布 = 硬裁切边界
    height: 128,                   // 角色总高（规范值）
    palette: { ... },              // 色板：draw(p) 里只用 p.xxx 取色，不写死色值
    anchors: { ... },              // 挂点表，见下
    headsets:     [ ...头部套装（含发型）... ],   // 单选 1 套
    faces:        [ ...表情... ],                // 单选 1 个
    bodies:       [ ...身体套装... ],            // 单选 1 套 = 5 件整体替换
    attachments:  [ ...挂件，数量不限... ]        // 跨分类复选、分类内单选
  });
})(typeof window !== 'undefined' ? window : globalThis);
```

## 基础部件三组（页面均单选；每组 ≥1 套，建议 ≥2 套以验证切换）

### headsets 头部套装（含发型，整头替换）

每套：`{ id, name, z: 5, draw: function(p) → svg字符串 }`，**绝对坐标**（128×128 空间）。
只画头型+发型，**不含五官**（五官归 faces）。

### faces 表情（单选 1 个，画在头上层）

每项：`{ id, name, z: 6, draw: function(p) → svg字符串 }`，**绝对坐标**（脸中心 ≈ (64,33)，
眼距 ±8.5、眼 y≈35.6~36.2、嘴 y≈45~45.5、腮红 ±11.5、y≈40~41.5）。
没有 `noBaseFace` 机制——基础表情就是 faces 里的一个普通选项。

### bodies 身体套装（单选 1 套 = 5 件，页面整体替换）

```js
{
  id: 'purple', name: '紫上衣·蓝短裙',
  legL:  { z: 1, draw: function (p) { ... } },   // 左腿（腿+鞋+裤/袜）
  legR:  { z: 1, draw: function (p) { ... } },   // 右腿
  torso: { z: 3, draw: function (p) { ... } },   // 躯干（脖子+上衣/连衣裙+衣领，女含裙男含外套）
  armL:  { z: 4, draw: function (p) { ... } },   // 左臂（袖+手），姿态统一垂放
  armR:  { z: 4, draw: function (p) { ... } }    // 右臂
}
```

5 件 key 固定 `legL/legR/torso/armL/armR`，缺件该件不画。draw 全部**绝对坐标**。

### 比例基准（chibi-3head-warmline-128 的纵向节奏，同 style 勿动）

| 部位 | y 范围 | 说明 |
|---|---|---|
| 头（含发） | 10 ~ 55 | 头**正圆** `ell(64,33,22,22)`，发盖顶 y=10（头部下移贴身，露脖 ≤4px） |
| 肩线 | 57 ~ 68 | 脖子 12 宽 `M58 47 L70 58` skinS；上衣**斜肩**（肩点 ~47/81@67 → 颈侧 58/70@58）+ 衣领（女圆领 / 男衬衫领，`#F7F1E8`） |
| 腰 / 下摆 | 84 ~ 94 | 女：裙摆 ~98；男：外套下摆 ~94 |
| 手 | y≈89.5 | 手部挂点两角色统一 `[40.5,89.5]` / `[87.5,89.5]` |
| 脚底 | 112 ~ 126 | 鞋=**圆角矩形** `rrect`（rx≈5.5，宽 17~18 高 11），底缘 ≤126 |

- 20% 规则的设计抓手：**双臂同姿态**（垂放）、发型外扩宽度相近、躯干宽 44~48；
  变体套装尽量复用同一几何（换色/换局部形状），跨角色、跨套装的 bbox 差自然 ≤20%。
- `getBBox` 不含描边：细线条部件（杖、剑）视觉比 bbox 宽。工具导出时已自动按最大
  `stroke-width` 外扩（pad = 1 + 最大描边宽，SVG/PNG 画布共用），无需手工预留；
  但**贴边警告**的判定仍是纯几何 bbox，粗描边部件视觉略越界属正常。

## 挂点表（anchors）

```js
anchors: {
  head:   [64, 21],    // 帽子挂这（offset [0,0] → 局部原点在发顶一带）
  body:   [64, 72],
  back:   [64, 72~74], // 披风/翅膀/背包；z 用 0.5（画在所有基础件后面）
  hand_l: [40.5, 89.5], hand_r: [87.5, 89.5],  // 武器；同 style 坐标一致才可跨角色复用
  foot_l: [...], foot_r: [...]                 // 鞋饰
}
```

## 挂件（attachments，跨分类复选 · 分类内单选 · 可反选）

```js
{
  id: 'hat_beret', name: '贝雷帽',
  cat: '帽子',               // 分类名（中文即可）：同 cat 只能选 1 件，不同 cat 可并存
  slot: 'head',              // 必须是 anchors 里的键
  offset: [0, 0],            // 局部原点 = anchors[slot] + offset
  z: 7.5,                    // 头饰 7~7.6 / 手持 6 / 背后 0.5
  draw: function (p) { ... } // 用挂点局部坐标作画！(0,0)=挂点，y 向下
}
```

- `type:'expression'` / `defaultOn` 已废除：表情走 faces 单选；挂件默认全不选。
- 手持武器若指向斜上，用 `<g transform="rotate(28)">` 包裹，剑尖避开头部（头部右缘 x≈88）。

## 编辑器与 overrides（手动微调产物）

- 每张资源卡右上角 **✎** 打开 SVG 编辑器（锚点/柄覆盖层为半透明圆点，不挡路径；
  Ctrl+Z 撤销 / Ctrl+Y 重做 ≤60 步，快照整栈重建、跨形状增删有效）：
  - 锚点拖拽（两侧手柄随行）、曲线手柄拖拽、数值输入（锚 X/Y、入柄/出柄 X/Y；椭圆/圆/矩形调 cx/cy/rx/ry 等）；
  - ＋线/＋环（视图中央新增路径，插在选中形状上层）、－形状；
  - ＋锚点（曲线段 De Casteljau 平滑细分，两侧手柄保留、曲线形状不变；直线段插直点）、
    －锚点（相邻段降为直线；删起点则后继成为新起点）；
  - ＋/－入柄·出柄（相邻 L 段升 C——手柄沿直线 1/3、2/3 放置；C/Q 段降回 L；柄属于段）；
  - 颜色：填充/描边取色器 + 「无」= none（none 状态色块仍可点击、选色即恢复）；描边宽恒显示，
    无描边时为 0，给宽度 >0 自动恢复上次描边色。
- 「完成并保存」把该资源的整段 SVG 标记（颜色已烘焙）存为 **override**，并写回角色 .js：
  文件末尾追加单行补丁 `/*__CHARFORGE_EDITS__*/registerEdits('<id>',{ '<key>':'<svg片段>', … });`。
  重复保存自动替换旧补丁行；**该标记行是保留行，手工编辑角色文件时不要动它**。
- 运行时 override 优先于 `draw()` 输出（预览/拼装/导出统一走它）。改动调色板不会影响已编辑资源——
  需要换色时在编辑器里重调，或删掉对应补丁行恢复 draw 输出。
- key 格式同资源 key：`<id>|head:<套装>` / `<id>|face:<表情>` / `<id>|body:<套装>:<legL|legR|torso|armL|armR>` /
  `<id>|att:<挂件>`（挂件 override 为挂点局部坐标片段）。
- 保存通道（不落下载优先）：①已授权角色文件夹 → 直接写回原文件名（写回角色**来源目录**——
  角色从 chars/ 子目录读出时补丁写回 chars/，不落上层；权限过期借保存点击 requestPermission 续期）；
  ②无句柄 → 现场 showDirectoryPicker 授权一次（记住文件夹，此后永久静默直写；用户取消则不保存不下载）；
  ③浏览器无 FSA → 才自动下载同名 .js 提示替换。showSaveFilePicker 单文件通道已移除。

## 存放与发现（默认 chars/）
- 角色 .js 默认放 `chars/` 文件夹（与 Editor.html 同级）。
- file://：授权任意文件夹都能读——顶层有 .js 读顶层；顶层无 .js 但存在 `chars/` 子目录时**自动下潜**读取。
- http(s)：自动扫描本目录索引；顶层无 .js 时自动扫描 `chars/`。
- 授权/发现记录来源目录（srcDir），编辑器保存补丁写回来源目录。

## 页面行为（Editor.html，勿改主逻辑）

- 加载顺序：注册器内联脚本 → `discoverChars()` 自动发现**同目录**下的 .js（http 走目录索引；
  file:// 走 FSA 文件夹授权一次 + 句柄存 IndexedDB，之后启动静默直读 / 一键重连）→ 主逻辑。
  **加/减角色不改 HTML**。
- 拼装 = 选中的 head + face + body 5 件 + 各 cat 选中的挂件，按 z 升序。
- 选择状态按角色独立记忆（切分页不丢）；默认 = 每组第 1 套、无挂件。
- 导出：**全部资源**（每个头部套装 / 表情 / 身体套装×5 件 / 挂件）+ **选中装配**（预览当前单选 + 已点挂件）
  —— SVG / PNG 按**尺寸倍率**（浮点输入，1 位小数，区间 (0,10]，非法/越界读取时门闩纠正）/ ZIP 全包。
  部件导出按 bbox + 描边外扩紧凑裁切（pad = 1 + 最大描边宽，画到 0~128 界外也完整不裁）；
  整体导出按 128 画框。
  命名：`<id>_head_<套装>` / `<id>_face_<表情>` / `<id>_body_<套装>_<leg_l|leg_r|torso|arm_l|arm_r>` /
  `<id>_att_<挂件>`；整体 `<id>_full.svg`、`<id>_full@<倍率>x.png`、`<id>_all.zip`（全部资源包）、`<id>_selected.zip`（当前装配包）。
- 自检：部件贴边/越界警告（卡片红框 + 基础面板底部汇总）、加载错误面板；
  **没有** 20% 一致性 UI 表（20% 规则在写角色时自查，页面不展示）。
- 基础部件/挂件卡片显示该资源的导出文件名（PNG 尺寸倍率变更时刷新）。
- 预览拖动定位、来源路径行（含「选择路径」按钮）等交互细节见 SKILL.md——本文件只管角色文件格式。
